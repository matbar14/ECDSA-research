Семейство стен: δ_req(Q, P_target)

Точки — измерение (Q=1, W=2^27); кривые — δ_req(Q,P) = log₂(Q/(−ln P)). «Стена» — семейство, а не число: P=1 недостижима (δ→∞), 100/100 на Q запросов живёт на кривой P=1−1/Q.

Ускорение верификации (пункт «precomputed [2^j]G»)

Reference-путь 0.776 мс/кандидат (cryptography derive 706 мкс + инварианты). Fast-путь: precomputed [2^j]G (j=0..39) + [2^134]G + сложения coincurve по битам offset + 2 инварианта = 0.341 мс (2.3×); EC-часть отдельно 706 → 161 мкс (4.4×). Эквивалентность fast-пути reference-верификации проверена на 200 случайных кандидатах по точным инвариантам. Pippenger-батчинг неприменим (база фиксированная, это не multi-scalar) — выигрыш только общий на все кандидаты precomputed-таблицы. Ускорение верификации не двигает δ-стену (вероятности те же), но дешевит fallback в filter-режиме.
